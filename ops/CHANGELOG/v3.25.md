# ATEM WEB MANAGER - ITERATION v3.25

## Changes in v3.25:
- Removed "MEDIA POOL" text completely. Renamed the primary header to `STILLS` and secondary section to `CLIPS`.
- Page 1 renders the 16 stills (slots 1-16) inside a standard 4x4 grid fitting the exact 424px container math.
- Page 2 renders Stills 17-20 in its own bounding box (Row 1), a 76px vertical spacer, and Clips 1-4 in its own bounding box with a 4px distance `CLIPS` header (matching Row 3 positions 9-12 of the 4x4 grid).
- Enabled bidirectional mouse wheel page navigation between Page 1 and Page 2.
- Added `MP 1` and `MP 2` toggle buttons to the right edge of the header row. Only one can be active at a time (turns orange). When active, clicking any still or clip slot immediately assigns it to that Media Player on the ATEM switcher.
- Added live `1` and `2` badges to media pool slots, tracking switcher state feedback for Media Player 1 and Media Player 2.
- Upgraded `bridge/server.js` to call `atem.downloadStill(index, 'rgba')` directly (letting the library decode RLE and convert colorspace) and downscaled the resulting buffer to a 320x180 BMP thumbnail for lightweight streaming over WebSocket.
- Connected drag-and-drop uploads directly to `atem.uploadStill()`, transferring dropped image data to the physical switcher slot.
- Suppressed `OPS.BAT` rendering per instruction.
- Synchronized version to v3.25.
